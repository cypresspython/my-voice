MY VOICE — FIRST PROTOTYPE

Open index.html on a computer for a preview. To install as an offline-capable iPhone Home Screen web app, host the entire folder on HTTPS (e.g., GitHub Pages), open its URL in Safari, wait for offline files to prepare, then Share > Add to Home Screen. While online, tap each button once. Turn on Airplane Mode, close and reopen the app, and verify EVERY button speaks. If offline testing fails, do not rely on the app.

Audio is an offline, synthetic male voice made with eSpeak. It is functional but robotic, and is NOT a natural neural voice. Replace WAV files with higher-quality licensed male synthetic recordings before final use, keeping filenames unchanged.

On older iPhones, support for Home Screen web apps and offline caches varies. Safari may remove cached files under storage pressure. This prototype is not an emergency alert system or a medically validated AAC device.

Do not use the ZIP directly on iPhone expecting offline installation: the service worker requires HTTPS.
